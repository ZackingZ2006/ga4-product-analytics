# GA4 Product Analytics

Phân tích phễu mua hàng theo phiên bằng BigQuery SQL trên dữ liệu GA4 mẫu của Google. Dự án kiểm tra chất lượng dữ liệu, phễu strict và phân tích độ nhạy weak.

[Truy vấn chính](01_ga4_funnel.sql) · [Nguồn dữ liệu](https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset)

Tải `ga4-product-analytics.zip` và giải nén để xem mã SQL, các bảng kết quả tổng hợp, kiểm thử và báo cáo. Xem README và `docs/HUONG_DAN_CHAY.md` trong thư mục để tái lập. Dữ liệu mẫu đã được làm nhiễu; kết quả mô tả mẫu này.
